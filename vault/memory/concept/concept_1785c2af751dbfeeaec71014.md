# 拉格朗日常数平移不变的热力学引力纲领 / Lagrangian-shift-invariant thermodynamic gravity program

Padmanabhan 的纲领要求引力场方程像非引力物质方程一样，在物质拉格朗日加入常数时保持不变。为此，它用零方向上的物质热密度 T_ab l^a l^b 作为变分对象；由于 l^a 为 null，该量在 T_ab 加上常数乘单位张量时不变，并把宇宙学常数型能量与通常热密度区分开。该纲领随后引入具有有限零点长度的量子修正几何：点邻域极限中的体积测度趋零而面积测度保持有限，从而构造时空原子的候选分布函数及引力热密度。这后一构造依赖特定 qmetric、零点长度和面积自由度假设；由此进一步估计宇宙学常数属于模型依赖的下游主张，不能仅由拉格朗日平移对称性或局部视界热力学唯一推出。
