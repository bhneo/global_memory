# 查询介导的 VLA 动作表征塑形

在预训练多模态骨干和动作策略头之间插入由指令条件化查询构成的动作接口，以先重组继承表征再预测动作，并让部分动作损失经该接口传播。该机制在论文的零样本仿真到真实导航设置中改善闭环结果，但不单独解决障碍感知规划。
