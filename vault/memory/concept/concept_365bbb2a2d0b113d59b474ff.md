# 协变熵界以光片而非空间体积限定熵 / covariant entropy bound uses light-sheets rather than spatial volumes

协变熵界将与给定曲面相关的熵限制在其正交、非膨胀的零光片上，而非任意被该曲面围住的空间体积；该构造在近经典几何、适当能量条件和光片终止规则下提出，不能作为无条件的普适信息容量定律。
