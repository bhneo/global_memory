# 条件化纠缠面积律与张量网络可模拟性 / conditional entanglement area laws and tensor-network simulatability

多体纠缠面积律是关于所选区域约化态的纠缠熵随区域边界而非体积缩放的条件化结论。其成立与否依赖局域性、空间维数、谱隙、玻色或费米统计、基态或热态、临界性以及非平衡过程；例如一维局域有隙体系有强面积律结果，而临界体系常出现对数修正，高维临界体系则既可能满足也可能违反面积律。纠缠缩放而非两点相关衰减本身更直接控制紧凑表示：一维面积律可严格支持矩阵乘积态近似。高维 PEPS 和 MERA 的构造本身满足面积律，但一般高维面积律是否足以保证小键维 PEPS/MERA 近似、以及网络能否高效收缩，仍缺少与一维同等的一般定理。因此，面积律不能被解释为任意量子态的普适定律，也不能自动推出高效经典模拟。
