# 单次前向动作条件世界模型的 rollout 吞吐量接口

动作条件世界模型若在训练中学习从先验到未来帧的漂移映射，可在推理时以单次前向生成候选动作序列的 rollout，从而为在线动作搜索或离线策略排序释放采样预算；其控制价值仍需分别验证预测保真、长时程误差和候选排序与真实结果的一致性。
