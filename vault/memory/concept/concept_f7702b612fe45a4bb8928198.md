# 反事实动作敏感度覆盖的鲁棒性修复 / Counterfactual action-sensitivity coverage repair

对已在 nominal 场景成功的模仿策略，构造保持任务状态、机器人状态和专家动作不变的 clean/nuisance 观测对，在归一化动作空间测量策略预测差，并按高漂移且响应特征互补的覆盖目标选择少量候选；选中 nuisance 观测继承原示范动作，与 clean 数据混合微调。该信号诊断当前策略对视觉扰动的敏感度，不是成功或安全保证；它依赖 task-preserving 假设、候选池覆盖和策略分布的合理距离，对多模态动作、延迟闭环失败和真机迁移需另行验证。
