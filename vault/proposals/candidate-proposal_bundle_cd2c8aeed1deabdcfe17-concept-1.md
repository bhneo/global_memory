# 有限真空纠缠熵只闭合低能 Einstein 引力 / finite vacuum entanglement entropy closes only low-energy Einstein gravity

量子场真空在空间分割两侧具有随面积增长的纠缠熵；若 Lorentz 不变的 UV 物理把该熵密度变为有限量，并且局部因果视界满足近乎平衡的 Clausius 关系，则热力学论证可要求因果结构成为动力学变量，并在长距离得到 Einstein 方程，其中 Newton 常数与视界熵密度的倒数相关。这个闭合不构成 UV 完成：论文没有识别或计数截止尺度上的微观自由度，纠缠熵随场物种数增长与 Newton 常数的尺度依赖必须通过尚未闭合的重整化关系协调，强耦合截止处的计数也不受微扰控制。高曲率尺度上通常有无穷多个有效作用量项同时重要，因此有限面积熵与低能 Clausius 关系不能单独导出特定的高曲率修正。
