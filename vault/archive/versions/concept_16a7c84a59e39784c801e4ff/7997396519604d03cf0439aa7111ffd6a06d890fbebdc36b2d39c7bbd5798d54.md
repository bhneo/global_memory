# 非特权开放世界移动操作评测边界

面向开放世界移动操作的评测应限制策略使用 RGB 等物理可获得输入，并把主动探索、视觉消歧和人机意图澄清纳入闭环任务；模拟与实机成绩必须连同具体工具、资产、episode 和本体条件解释。
