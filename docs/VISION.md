# Vision

Galois is local-first scientific memory for people who work with AI assistants.
It stores sources, evidence, open questions and changing beliefs so several
tools can share one governed knowledge base — without treating chat summaries
as truth, and without becoming an agent runtime that runs tools or experiments.

## What it aims to be

A personal long-term cognitive infrastructure — not a bookmark folder, template
library, or RAG bolt-on for a single model.

It serves two modes at once:

- build actionable knowledge around questions, projects and goals
- keep material that is still fuzzy, contested or cross-domain, so later
  connections remain possible

The underlying structure is a typed graph with reasons and sources. Trees,
directories, project views and Context Packs are temporary views around a
question — not the truth layer.

Success is not “how much was stored,” but:

- you still own the originals
- conclusions can be traced to evidence
- belief changes keep history
- different assistants obey the same governance rules
- indexes, models and UIs can be replaced and rebuilt

## How cognition enters memory

Experience becomes a typed **Input**, then a non-factual **Reflection**, before
any semantic knowledge update. A daily pass digests a small queue; a weekly
cadence audits recent admission and incrementally synthesizes durable research
directions. Cross-direction candidates are optional and evidence-bounded.

Galois stays the truth and cognitive-evolution layer. Assistants do the
thinking outside the core.

## Scientific cognition (north star)

Long term, four responsibilities stay distinct rather than collapsed into one
blob:

| Graph | Answers |
|---|---|
| **Evidence** | What did the world actually provide? |
| **Model** | How do we currently understand it? |
| **Possibility** | What might be true? |
| **Experiment** | How would we know? |

Today the system records attention, connection feedback and real project use
needed to grow those graphs later. It does **not** claim automatic scientific
discovery.

## Trust without laundering uncertainty

New material should reuse, support, refine, limit or contradict existing
knowledge while preserving Raw, Evidence, prior versions and governance
history. Working may evolve automatically; every Trusted change must be
verifiable, explainable and rollbackable. Canonical promotion stays scarce and
human-confirmed.

**Memory Tier** asks: is this worth stable long-term recall?  
**Epistemic Status** asks: what do we actually know?

Keeping those separate allows durable open questions, hypotheses and analogies
without presenting them as established facts.

## Operating cost

Memory should become useful at Working cost, gain confidence through periodic
consolidation, and spend human attention mainly on exceptions and high-impact
Canonical promotion — not on approving every item.
