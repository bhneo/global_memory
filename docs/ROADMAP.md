# Roadmap

Product direction without internal delivery codes. For current engineering
status see [PROJECT_STATE.md](../PROJECT_STATE.md).

## Now (in use)

- Capture, immutable Raw/Source, extraction, Working / Trusted / Canonical gates
- Input → Reflection → direction-scoped Cognitive Synthesis (Daily / Weekly Dream)
- Research signals: annotation, activation, connection feedback (trust-orthogonal)
- Progressive routing and bounded Context Packs for assistants
- Read-only MCP for multiple hosts; Obsidian rebuildable views
- Receipts, demotion events, exception and promotion queues
- Local acceptance and doctor/lint/raw integrity checks

Still calibrating from real use: trust thresholds, review compression, a few
legacy claim/concept exceptions, and remote CI sync when you push.

## Next

- Evaluate Reflection usefulness, Context quality and review compression before
  adding more automation
- Mechanism compiler: turn reviewed `possible_mechanisms` into Phenomenon,
  Mechanism, Objective, Constraint, Invariant, Feedback, Failure Mode and
  Prediction — without treating Reflection as fact
- Stronger Chinese retrieval / relation ranking; optional local rebuildable
  embeddings only if they never become the truth source
- Public packaging: engine + synthetic fixtures, no private vault
  ([RELEASE_BOUNDARY.md](RELEASE_BOUNDARY.md))

## Later

- Structural analogy engine (topical distance + shared mechanism + explicit difference)
- Hypothesis lab: connection → conjecture → competing hypotheses → prediction →
  falsifier → smallest experiment
- Experiment loop: import human/agent-run results as Input; Galois does not
  execute experiments itself

## Done (foundations)

- Global content-addressed raw store, refresh versioning, approval recovery
- Bundle compiler, atomic claims, typed relations, source quality gates
- Context Pack profiles and bounded relation expansion
- Contradiction audit, hash-locked synthesis proposals, explainable discovery
- Multi-assistant thin entry (receipt → Working; Canonical human-only)
- Orthogonal Memory Tier and Epistemic Status

## Explicitly deferred

Graph databases, complex frontends, browser plugins, WeChat bulk capture,
multi-agent orchestration frameworks, automatic overnight vault rewrites, and
heavyweight ontologies.
